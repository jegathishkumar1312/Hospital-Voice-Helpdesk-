# 📌 Project Overview

Hospital Voice Helpdesk is a voice-enabled NLP assistant designed to help patients and visitors inside hospitals.

The system can answer hospital-related queries such as:

* ICU location
* Pharmacy details
* Emergency availability
* Hospital timings
* Department guidance
